# Treemap Algorithm

An interactive visualization project built in Python that represents hierarchical data as nested rectangles. It uses recursive tree structures to explore file sizes and computer science research-paper data.
Features
- Visualizes files and folders as a treemap.
- Sizes rectangles according to the data they represent.
- Supports expanding and collapsing branches of the hierarchy.
- Provides interactive controls for exploring and modifying the visualization.
- Models research-paper data using a specialized tree structure.
- Uses Pygame to render the graphical interface.
